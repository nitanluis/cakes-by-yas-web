# Traducción Bernice → Cakes by Yas

Dirección elegida por el usuario el 2026-10-30: fidelidad a composición y animaciones de Bernice, con marca, pasteles y operación de Yas. Base verificable: [sistema medido](SISTEMA-MEDIDO.md). Este documento decide qué hacer con cada familia; no mezcla decisiones con medidas originales.

## Identidad que conserva su uso propio

El lettering y los degradados originales del logotipo permanecen dentro de la marca; no convierten cada botón en un degradado. El isotipo no se sustituye por un dibujo nuevo. La cara, textos, fotos, ubicación, política de entregas, reseñas y hechos comerciales de Bernice no se trasladan a Yas. Coral será la única familia de acción; el texto oscuro sobre coral se elegirá por contraste, sin dar por hecho que blanco pequeño resulta legible.
